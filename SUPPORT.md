# Help / Aide

**EN:** Read the installation and upgrade guides first. Use [Discussions](https://github.com/farhadtoor/voilavoila-cms/discussions) for setup questions; use [Issues](https://github.com/farhadtoor/voilavoila-cms/issues) for a reproducible defect. Include CMS/PHP/browser versions and a minimal example. Share redacted excerpts, never your storage directory, complete logs, backups, cookies or owner credentials. For vulnerabilities, follow [SECURITY.md](SECURITY.md). Community support is voluntary, without a guaranteed response time.

**FR :** Consultez d’abord les guides d’installation et de migration. Utilisez [Discussions](https://github.com/farhadtoor/voilavoila-cms/discussions) pour une question et les [Issues](https://github.com/farhadtoor/voilavoila-cms/issues) pour un défaut reproductible. Indiquez les versions CMS/PHP/navigateur et un exemple minimal. Partagez des extraits anonymisés ; jamais le stockage, les journaux complets, sauvegardes, cookies ou identifiants. Pour une faille, suivez [SECURITY.md](SECURITY.md). L’aide communautaire est bénévole, sans délai garanti.

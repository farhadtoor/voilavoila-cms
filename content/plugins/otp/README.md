# VoilaVoila Authenticator OTP 1.0

Requires CMS 1.3.1 for authentication enforcement. [English guide](../../../docs/OTP.md) · [Guide français](../../../docs/OTP.fr.md).

Install the small native plugin ZIP, activate it, reauthenticate, scan the locally generated QR with a TOTP app, confirm one code and store recovery codes offline. Use `php content/plugins/otp/bin/otp.php status` for local status.

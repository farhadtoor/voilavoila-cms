# Comments 1.0.0 / Commentaires 1.0.0

Requires VoilaVoila CMS 1.2.0+, API 1. Ships inactive. Enable in Plugins, moderate in Comments. Guest messages always require owner approval. No public accounts or email collection. Uses SQLite plugin data, capped at 1,000 messages / 1 MiB; no new database table. Deactivation/file removal retains data. Explicit purge requires current password and PURGE. Portable backups include messages. Licensed under the repository MIT license.

Nécessite VoilaVoila CMS 1.2.0+, API 1. Livré désactivé. Activez dans Extensions, modérez dans Commentaires. Chaque message visiteur attend l’approbation du propriétaire. Sans compte public ni collecte d’e-mail. Stockage SQLite dans les données du plugin, 1 000 messages / 1 Mio, sans nouvelle table. Désactivation/suppression des fichiers conserve les données. La purge explicite demande le mot de passe actuel et PURGE. Les sauvegardes portables incluent les messages. Licence MIT du dépôt.

VoilaVoila CMS 1.5.0

CMS natif, propriétaire unique, PHP 8.3+ et SQLite par défaut. Les fonctions prévues pour 1.5 et 1.6 sont regroupées.

Installation neuve

Le profil de production ferme install.php. Utilisez php bin/console.php install < /chemin/prive/installation.json avec un JSON privé contenant name, email et password. Pour une installation Web, activez temporairement le profil Apache/Nginx documenté, puis rétablissez le profil de production.

Mise à jour

Conservez le stockage privé, les comptes, les médias et les modules personnalisés. Utilisez le paquet de mise à jour 1.4.0 vers 1.5.0 et son guide, après sauvegarde complète.

English

Production exposes four native PHP controllers. Use CLI installation or the temporary installation profile, then restore production rules. Back up code, all private storage and separate business databases before upgrading. New uploads require private quarantine and separate review; no WordPress execution engine is bundled.

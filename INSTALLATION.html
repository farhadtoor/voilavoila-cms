VoilaVoila CMS 1.5.1

CMS natif, propriétaire unique, PHP 8.3+ et SQLite par défaut. Les fonctions prévues pour 1.5 et 1.6 sont regroupées.

Installation neuve

Ouvrez install.php en local ou sur le site en HTTPS. Saisissez la clé privée de storage/setup-key.php (accessible par SFTP) ou lancez php bin/console.php install-key. L’installateur se verrouille dès que le propriétaire est créé ; la clé est supprimée. La commande php bin/console.php install < /chemin/prive/installation.json reste une option sans interface Web.

Mise à jour

Conservez le stockage privé, les comptes, les médias et les modules personnalisés. Cette branche prépare le code 1.5.1 ; utilisez le paquet et le guide de mise à jour publiés avec sa release pour mettre à jour un site.

English

The one-time installer is available locally or over HTTPS with the private setup key. It locks and removes the key after the owner is created. CLI installation is also available. Five native PHP controllers are exposed, including the locked installer. Back up code, all private storage and separate business databases before upgrading. New uploads require private quarantine and separate review; no WordPress execution engine is bundled.

# Roadmap / Feuille de route

This is a proposal queue, not a delivery commitment. / Cette liste présente des orientations, sans engagement de date.

| Priority / Priorité | Work / Travail | Acceptance / Validation |
| --- | --- | --- |
| Now / Maintenant | First real GitHub CI runs; confirm PHP 8.3/8.4/8.5 / Premiers passages CI réels | All required jobs green; publish actual results / Jobs requis verts, résultats réels publiés |
| Now / Maintenant | 5–10 pilot self-hosted installs / 5 à 10 installations pilotes | Redacted hosting matrix and concrete defects / Tableau d’hébergements anonymisé et défauts précis |
| Next / Ensuite | Apache/Nginx HTTPS and production Docker validation / Validation HTTPS et Docker de production | Storage denied, login works, original JPEG/WebP imports verified / Stockage refusé, connexion et imports vérifiés |
| Next / Ensuite | Keyboard and contrast improvements / Clavier et contrastes | Reproduction, small fix, browser check / Reproduction, correction ciblée et contrôle navigateur |
| Next / Ensuite | Native theme/plugin examples / Exemples de modules natifs | API 1 manifest, rights, no secrets, isolated test / Manifeste API 1, droits, aucun secret et essai isolé |
| Later / Plus tard | Documented 1.1.x patch process and more migration fixtures / Correctifs 1.1.x et cas de migration | Upgrade and rollback validated / Mise à jour et retour vérifiés |

The project retains one owner. Public accounts, roles, payments, a WordPress compatibility layer and a plugin marketplace are outside the current scope. / Le projet conserve un propriétaire unique. Comptes publics, rôles, paiements, compatibilité d’exécution WordPress et place de marché sont hors du périmètre actuel.

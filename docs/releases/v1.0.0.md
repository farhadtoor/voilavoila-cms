# VoilaVoila CMS 1.0.0 — initial release / première version

## English

The initial standalone personal CMS: one owner, a public profile, FR/EN pages/posts, revisions, drafts/scheduling/previews, media, two native themes and three plugins (workspace, SEO and an external PASS link). Portable backups and a limited WordPress WXR 1.2 importer are included.

This historical version stores editorial state as guarded JSON, converts images to PNG and wraps media in private PHP-guarded files. For a new installation, use **1.1.0**, which moves content to SQLite and preserves original media formats. PHP 8.3+ is required; see the supplied installation guide for extensions.

Attached: the unchanged original installable ZIP and its SHA-256 checksum. The Git tag identifies the imported snapshot; the import does not recreate original development dates. The supplied historical reports record 50 HTTP and 29 browser checks, not an independent security audit. Docker/real HTTPS hosting/macOS launcher were not executed in those checks.

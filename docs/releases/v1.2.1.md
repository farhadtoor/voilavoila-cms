# VoilaVoila CMS 1.2.1 — release notes / notes de version

26 October 2026.

## English

This patch makes release delivery verifiable: clean active paths, a flat installable ZIP, commit metadata, complete SHA-256 manifest, bounded validation and staged extraction. The test image verifies declared package bytes, including the bundled SDK ZIPs.

A read-only hosting preflight is available in Tools and through `php bin/console.php doctor --json` without initializing a database. Obsolete GD calls are removed for PHP 8.5. Original media, owner credentials, settings, activation choices and SQLite schema are preserved.

CI builds one package and tests its extracted contents across PHP 8.3/8.4/8.5, upgrades/rollback and the real Chromium journey. Native themes, plugins, documents, comments and offline WordPress support remain available.

See [upgrade instructions](../../MISE-A-JOUR-1.2.1.md), [GitHub procedure](../../GITHUB-v1.2.1-FR-EN.md) and [hosting pilots](../HOSTING-PILOT-FR-EN.md). Real hosting qualification is pending; attach actual validation evidence to the public release.

## Français

Ce correctif fiabilise la distribution : chemins actifs propres, ZIP installable plat, métadonnées du commit, manifeste SHA-256 complet, validation bornée et extraction préparée dans un dossier neuf. Le conteneur de test vérifie aussi les octets des fichiers déclarés, dont les ZIP du SDK.

Un diagnostic en lecture seule est disponible dans Outils et par `php bin/console.php doctor --json`, sans initialiser de base. Les appels GD obsolètes sont retirés pour PHP 8.5. Les originaux médias, identifiants, réglages, activation des extensions et schéma SQLite sont conservés.

La CI construit un paquet commun et teste son contenu extrait sur PHP 8.3/8.4/8.5, les mises à jour/retours arrière et le véritable parcours Chromium. Les thèmes, extensions, documents, commentaires et fonctions WordPress existants sont conservés.

Lire la [mise à jour](../../MISE-A-JOUR-1.2.1.md), la [procédure GitHub](../../GITHUB-v1.2.1-FR-EN.md) et les [pilotes d'hébergement](../HOSTING-PILOT-FR-EN.md). La qualification sur hébergement réel reste en attente ; joindre les preuves réelles à la release publique.

# VoilaVoila CMS 1.3.1 — Engine + Authenticator

FR : petit correctif d’intégration de l’authentification forte, avec une extension OTP indépendante (QR local, TOTP, codes de secours et récupération SSH). Le moteur WordPress facultatif passe en 0.2 : thèmes/plugins réels, modules volumineux dont WooCommerce, profil de compatibilité et copie éditoriale depuis SQLite. Les données natives restent dans le CMS ; les données métier WP restent dans son SQL dédié. Le pack lourd tiers est distribué séparément.

EN: small authentication integration update with an independent OTP plugin (local QR, TOTP, recovery codes and local recovery). Optional WordPress Engine 0.2 supports real themes/plugins, large modules including WooCommerce, a compatibility profile and native editorial copies. Native data stays in CMS; WordPress business data stays in dedicated SQL. The large third-party pack is distributed separately.

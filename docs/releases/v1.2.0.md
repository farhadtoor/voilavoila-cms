# VoilaVoila CMS 1.2.0 — Documents, comments & WordPress migration

## Français

Cette version ajoute l’attachement de PDF, DOCX, ZIP et CSV aux pages/articles, un plugin facultatif de commentaires modérés et un import WordPress hors ligne enrichi.

- Documents : extension/MIME réel, validation structurelle DOCX/ZIP, CRC et limites ; originaux et extensions conservés ; téléchargement forcé, nosniff et accès privé/public.
- Éditeur : sélection d’un document public et insertion dans la langue active.
- Commentaires 1.0.0 : visiteurs sans compte, modération obligatoire, jeton signé distinct de l’accès propriétaire, CSRF/origine, leurre, limites, export JSON et purge authentifiée.
- WordPress : WXR 1.0–1.2 avec ZIP uploads local, résumés/dates/mots-clés, images/documents, couvertures publiques, liens internes, galeries simples, commentaires en attente, dédoublonnage stable et rapport privé.
- WordPress Porter 1.0.0 inclus sans modification et désactivé ; conversion limitée, brouillon manuel pour les cas complexes.
- Compatibilité minimale CMS/PHP contrôlée dans les manifestes ; API 1 et schéma SQLite existant conservés.
- Documentation FR/EN, procédure GitHub, tests isolés et CI fournis.

Mise à jour : sauvegardez puis conservez `storage`, vos thèmes/plugins personnalisés et vos accès existants. Les nouveaux plugins sont désactivés. Voir `docs/fr/mise-a-jour-1.2.md`.

DOCX/ZIP suivent une politique stricte pouvant refuser certains documents légitimes. Aucun antivirus ni compatibilité universelle WordPress n’est annoncé. Les médias manquants/refusés demandent une reprise ; aucun téléchargement distant ni redirection 301 automatique.

## English

This release adds PDF/DOCX/ZIP/CSV attachments to pages/posts, an optional moderated-comments plugin and expanded offline WordPress migration.

- Documents: actual extension/MIME and DOCX/ZIP structure/CRC/size validation; original bytes/extensions; forced downloads, nosniff and private/public access.
- Editor: public-document picker inserts into the active language.
- Comments 1.0.0: guests without accounts, mandatory moderation, signed token separate from owner access, origin/CSRF controls, honeypot, limits, JSON export and authenticated purge.
- WordPress: WXR 1.0–1.2 plus local uploads ZIP, excerpts/dates/tags, images/documents, public covers, internal links, simple galleries, pending comments, stable deduplication and private report.
- Unchanged WordPress Porter 1.0.0 included inactive; limited conversion and manual drafts for complex cases.
- Minimum CMS/PHP manifest checks; existing API 1 and SQLite schema retained.
- FR/EN documentation, GitHub procedure, isolated tests and CI supplied.

Upgrade: back up, preserve `storage`, custom themes/plugins and owner access. New plugins remain inactive. See `docs/en/upgrade-1.2.md`.

Strict DOCX/ZIP policy may reject legitimate documents. No antivirus or universal WordPress compatibility is claimed. Missing/rejected media require review; no remote downloads or automatic 301 redirects.

## Validation

See `docs/VALIDATION.md` and the versioned JSON reports. Local PHP 8.3.6 validation is separate from the supplied GitHub PHP 8.3/8.4/8.5 matrix; hosting and remote CI must still be checked in their real environments. The release has not been deployed or published automatically.

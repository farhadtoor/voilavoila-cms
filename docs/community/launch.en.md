# Launch announcement draft

VoilaVoila CMS is a small self-hosted CMS for a personal site: one owner, a profile, pages/posts, media, native themes and plugins. It runs on PHP with SQLite, without a Composer/npm build or a database server.

Version 1.1.0 adds SQLite editorial storage, separate access/error text logs and original media formats. The project includes English/French guides and a migration path from the initial version.

I am looking for early installation feedback: which PHP/hosting setup did you try, did installation work, and what blocked you? Documentation corrections, accessibility feedback and small native modules are welcome. Its scope is a personal CMS; the PASS integration is an external link, not a payment engine.

Repository and installation: https://github.com/farhadtoor/voilavoila-cms
Questions: https://github.com/farhadtoor/voilavoila-cms/discussions
Please use the private reporting instructions in SECURITY.md for vulnerabilities and never post real storage or credentials.

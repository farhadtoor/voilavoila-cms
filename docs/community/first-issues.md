# Suggested first issues / Premières tâches proposées

These are draft tasks, not existing GitHub issues or confirmed defects. Scope each before assigning `good first issue`. / Ces tâches sont des brouillons, pas des tickets existants ni des défauts confirmés. Délimitez-les avant d’ajouter `good first issue`.

1. **Hosting recipe / Recette d’hébergement.** On a disposable PHP host, document PHP extensions, storage denial and installation steps without account data. Acceptance: repeatable instructions plus CMS/PHP/server versions in EN/FR. / Sur un hébergement jetable, documenter extensions, protection du stockage et installation, sans accès. Réussite : recette rejouable et versions, en FR/EN.
2. **Keyboard walkthrough / Parcours clavier.** Check installation/login/editor/media at desktop/mobile sizes, report one reproducible obstacle before changing code. Acceptance: exact keys, expected behavior, small fix and browser verification. / Vérifier le clavier sur les principaux écrans, isoler un obstacle ; touches exactes, comportement attendu, correction ciblée et contrôle navigateur.
3. **Translation consistency / Cohérence des traductions.** Compare one guide pair and fix actual meaning differences. Acceptance: both files reviewed and local links valid. / Comparer une paire de guides ; sens conservé, deux fichiers relus et liens valides.
4. **Portable browser suite / Suite navigateur portable.** Discuss dependencies and runner design first. Acceptance: temp installation, no real storage, test for one editor workflow, documented browser install and clean exit. This may be `help wanted` rather than a beginner issue. / Discuter dépendances et lanceur ; installation temporaire, aucun stockage réel, un parcours éditeur, installation navigateur et arrêt propres. Tâche plutôt `help wanted` si complexe.
5. **Native plugin example / Exemple d’extension.** Propose a tiny shortcode module based on the SDK. Acceptance: API 1 manifest, direct-access guard, escaped output, no external secrets, install-inactive behavior verified, EN/FR guide. / Petit shortcode natif : manifeste API 1, garde d’accès, sortie échappée, aucun secret, installation inactive vérifiée et guide FR/EN.

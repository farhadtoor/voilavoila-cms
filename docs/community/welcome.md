# Welcome / Bienvenue

## English

Welcome to VoilaVoila CMS. Start with the README installation guide, then tell us what you built and which PHP/host configuration you tried. English and French are welcome.

Use Q&A for help, Ideas for early proposals, Show and tell for your site and Issues for reproducible defects. Read CONTRIBUTING before opening a PR. Keep owner data, full logs and backups private; use SECURITY.md for vulnerabilities. Please follow the Code of Conduct. Support is voluntary and replies may take time.

## Français

Bienvenue sur VoilaVoila CMS. Commencez par le guide du README, puis présentez votre usage et la configuration PHP/hébergement essayée. Français et anglais acceptés.

Utilisez Q&A pour l’aide, Ideas pour les propositions, Show and tell pour vos sites et Issues pour les défauts reproductibles. Lisez CONTRIBUTING avant une PR. Gardez accès, journaux complets et sauvegardes privés ; pour une faille, consultez SECURITY.md. Respectez le code de conduite. L’aide est bénévole et les réponses peuvent prendre du temps.
